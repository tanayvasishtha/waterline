# Waterline

Waterline reads the staff gauges that USGS river cameras already see, checks every reading against the official sensor, takes another look or abstains when the picture can't be trusted, and asks a technician to review the sensor when camera and gage disagree.

Work in progress for the OpenCV AI Competition 2026. Built on OpenCV 5 and AWS.
